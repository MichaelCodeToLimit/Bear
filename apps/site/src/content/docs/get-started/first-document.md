This walk-through takes you from the home screen to a saved `.docx` file in a few minutes.

## Start Bear

When Bear opens you land on the launcher: a home screen with a tile for each app. Apps that are ready to use are bright, and the ones still being built say "coming soon".

Click the **Write** tile. A blank page opens, ready for typing.

## Write something

Type a title, press Enter, and keep going. The ribbon along the top has tabs for Home, Insert, Layout and View.

- On **Home**, pick a font and size, make text bold or italic, and choose a heading style for your title.
- On **Insert**, add a table, a picture, a link or a page break.
- On **Layout**, switch between Letter and A4, and between portrait and landscape.

Press **Ctrl+F** to find a word, or **Ctrl+H** to find and replace it.

## Save it as a .docx

Open the **File** menu and choose **Save**. Pick **.docx** as the file type and give the document a name. Bear writes a standard document that other word processors can open too. You can also save as `.html` or `.txt`. To keep the original and make another file, use **Save a copy as**.

Once the file has a name, **AutoSave** can keep it up to date for you. If you close the window with unsaved changes, Bear asks what you want to do first, so nothing gets lost by accident.

## Open it again later

Choose **Open** on the File menu to browse for a file. Bear also remembers your recent files, so your latest documents are one click away. You can also double-click a `.docx` in your file manager and Bear will open it.
