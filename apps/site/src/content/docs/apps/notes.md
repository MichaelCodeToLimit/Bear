Notes is Bear's notebook for ideas, meeting notes, lists and anything you want to find again. It saves automatically, so there is no Save button to remember.

## How notes are organised

Notes has three levels, like a paper binder:

1. **Notebooks** hold everything about a big topic, such as Work or Recipes.
2. **Sections** are coloured tabs inside a notebook.
3. **Pages** are where you write.

Create a notebook, add a few sections, then add pages to each one. Pick a colour for each section to make it easy to spot.

## Write on a page

Pages use the same editor as Write, so you get rich text and more:

- To-do **checklists** you can tick off.
- **Tables** for lining things up.
- **Pictures**, pasted or inserted.
- **Links** to the web.

## Find things

Search looks across every notebook at once, so you do not need to remember where you put something.

## Rearrange

Changed your mind about where a page belongs? Move it to another section.

## Where your notes live

Notes keeps its data in Bear's own data folder on your computer. Changes are written safely, so a crash or power cut cannot leave a half-written file behind.
