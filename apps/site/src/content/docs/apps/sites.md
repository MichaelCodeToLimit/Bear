Sites gives a team a home page. Today your sites live on your own computer, so they are a good way to organise a project. Sharing a site with other people needs a server that does not exist yet.

## Create a site

Make a new site and give it a name. It starts with a home page you can fill in. Like Notes and Tasks, it saves automatically into Bear's data folder.

## The home page

The home page can show:

- A **welcome** message for visitors.
- **News**, the latest posts from the site.
- **Quick links** to the places people use most.
- **Recent documents** from your document library.
- A linked **Tasks** list, so the team's to-dos sit right on the front page.

## Pages and news

Add **pages** for things that stay put, like a project overview or a process. Add **news posts** for updates that happen once. Both use the same editor as Write, so you can add headings, lists, tables and pictures.

## Document library

Connect the library to **any folder** on your computer. The files in it show up in the site, and files that Bear understands open in Bear when you click them.

## Settings

Each site has a settings page for managing the site itself.
