# Bear Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the animated five-page Bear website (Home, Tour, Docs, Playground, Download) in `apps/site` and deploy it to GitHub Pages at `https://michaelcodetolimit.github.io/Bear/`.

**Architecture:** An Astro static site in the pnpm workspace. Pages are `.astro` files sharing one `BaseLayout`. The interactive parts are React islands: the Tour picker, the Playground toys and docs search. Pure logic lives in `src/lib/*.ts` with Vitest tests. Page behaviour is covered by a separate Playwright suite against `astro preview`. App names and colours come from `@bear/core`. The Download page reads the latest GitHub Release at build time.

**Tech Stack:** Astro 7, @astrojs/react, React 18 (the workspace version), TypeScript, Motion, Matter.js, Pagefind, fast-formula-parser, Vitest, Playwright, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-14-bear-site-design.md`. Read it alongside this plan; copy and layout details live there.

**Branch:** work on `feat/site`, cut from `main`. Merging to `main` is what deploys.

## Global Constraints

- Dependencies must be MIT-compatible. Never add a GPL package.
- Use the newest version of each new package that is at least 7 days old, to satisfy pnpm `minimumReleaseAge`. At writing: `astro@7.3.8`, `@astrojs/react@7.0.1`, `matter-js@0.20.0`, `@types/matter-js@0.20.2`, `pagefind@1.5.2`, `fast-formula-parser@^1.0.19`. `motion@14.2.0` is too new (2026-10-13), so use the newest older `motion` release.
- Node ≥ 22.12, which Astro 7 requires. CI uses Node 22.
- Base path `/Bear/`. Every internal link and asset goes through `url()` from `src/site.config.ts` or `import.meta.env.BASE_URL`. Never hard-code a leading `/`.
- Original branding only:
  - Use the Bear logo from `apps/desktop/build/icon.png`, imported with `astro:assets`.
  - No Microsoft names or logos, except naming the .docx, .xlsx and .pptx formats.
  - The footer includes: "Bear is an independent project. It is not affiliated with or endorsed by Microsoft."
- App id, name, tagline, colour and `ready` always come from `APPS` in `@bear/core`. Never copy them into site code.
- Cozy tokens:

  | Token | Value |
  |---|---|
  | Cream | `#fbf4ea` → `#f1e2cc` |
  | Ink | `#3b2a1a` |
  | Motion storage key | `bear-motion` |
  | Theme mixer storage key | `bear-mix` |

- Wrap every `localStorage` access in try/catch.
- Any element hidden for a reveal animation must be visible without JavaScript. Hide it only under `html.js`.
- Home ships at most 60 KB of JavaScript, gzipped.

## Review Focus

1. **JavaScript disabled:** everything on every page must be readable, including reveal content, the Tour list and Download files. *Test: Task 3 `no-js.spec.ts`.*
2. **Unknown or coming-soon deep link** (`tour/#nope`, `tour/#chat`): no crash. `#nope` shows the grid with nothing open. `#chat` opens the coming-soon panel. *Test: Task 6.*
3. **Corrupted saved theme** (`bear-mix` set to garbage or old shape): the defaults load and nothing throws. *Test: Task 11 `parseSavedMix`.*
4. **Bad formulas in the mini sheet** (self-reference, unknown function, divide by zero, text in SUM): each cell shows an error code and nothing throws. *Test: Task 10.*
5. **Partial or missing release** (only Windows files, a Mac visitor, the API down or rate-limited): the page shows what exists and falls back gracefully. *Test: Task 8 `pickBest` and fallback.*

### Task 8: Download page

**Files:**
- Create: `src/lib/releases.ts`, `src/lib/releases.test.ts`, `src/scripts/detectOS.ts`, `src/pages/download.astro`, `e2e-site/download.spec.ts`

**Interfaces:**
- Produces:
  - `type OS = 'windows' | 'mac' | 'linux'`
  - `interface DownloadFile { name: string; url: string; size: number; os: OS; label: string; recommended: boolean }`
  - `interface ReleaseInfo { version: string; date: string; notesUrl: string; files: DownloadFile[] }`
  - `classifyAsset(name: string): { os: OS; label: string; recommended: boolean } | null`. Labels come verbatim from the spec table. `recommended` is true for `.exe`, `.dmg` and `.AppImage`. The match is case-insensitive.
  - `formatSize(bytes: number): string`. It returns `Math.round(bytes / 1e6) + ' MB'`, and `'<1 MB'` below 1e6.
  - `toRelease(json: unknown): ReleaseInfo | null`. It reads `tag_name` (with a leading `v` stripped), `published_at`, `html_url`, and `assets[].{name, browser_download_url, size}`. It returns `null` when the shape is invalid or no asset classifies.

    | Field | Range |

    | `round` | 0 to 2 |
    | `speed` | 0.25 to 2 |

  - `DEFAULT_MIX: Mix = { hue: 0, round: 1, speed: 1 }`

  - `clampMix(m: Partial<Mix>): Mix`. Missing or NaN fields take their default.
